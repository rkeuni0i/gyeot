# 곁 — 상담실 곁의 사안처리 동료

이산중학교 사안처리·상담 도우미(테스트용 챗봇). 가제 MindGuide에서 이름을 바꿨습니다(2026-10-19). 프로젝트 폴더는 `gyeot`(2026-10-19 `mindGuide_test`에서 이름 변경)이고, 저장소 파일은 `index/gyeot.db`(이전 `mindguide.db`), 환경변수 `MINDGUIDE_MODEL`은 그대로 씁니다. 저장소 파일이 없으면 앱은 빈 저장소를 만들지 않고 안내를 띄웁니다(새로 만들기는 `build_index.py`). 로고(서로 기댄 잎 두 장)는 `docs/brand/`에 있고 `python docs/brand/make_logo.py`로 다시 만듭니다.

학교에 혼자 근무하는 상담사가 **절차·기한·법적 의무·학교 규정·양식·기관 연계**를 빠르게 확인하도록 돕는 챗봇입니다.
**이산중학교(경기) 전용** 챗봇입니다(Wee 클래스 운영, 전문상담교사 1명 배정 — 학교 홈페이지에서 확인). 근거 자료는 두 개이고 **이산중 규정을 먼저** 확인합니다. 답변의 사실 문장마다 `[이산중 p.쪽]` 또는 `[가이드북 p.쪽]` 근거를 답니다.

등록 자료 10개(2026-10-23, 청크 1,689개). 기본 자료 4개는 질문 유형별 확인 순서의 고정 자리, 추가 자료 6개는 자료 관리에서 평가·승인해 넣은 것입니다.

- 질문 유형 라우팅: 질문을 먼저 아래 유형으로 나누고, 유형마다 확인 순서·검색 몫·답변 형식을 다르게 씁니다(`rag.py`의 `QTYPES`). 유형 판단은 검색어 생성과 같은 Gemini 호출에서 함께 해서 추가 호출이 없습니다. 화면 답변 위에 "🔎 질문 유형 · 확인 순서"가 표시됩니다.

  | 유형 | 확인 순서 | 답변 형식 |
  |---|---|---|
  | 학교 맞춤형 | 이산중 → 가이드북 → 매뉴얼 | 이산중 규정 → 지금 해야 할 일 |
  | 학교폭력 절차·법 | 가이드북 → 이산중 → 매뉴얼 | 사실은 바로, 상황은 법정 절차 순서 |
  | 용어·개념 정의 | 가이드북 → 사이버상담 → 디지털상담 → 이산중 | 법적 정의 → 매뉴얼 정의·유형 → 비슷한 용어 차이 |
  | 상담 가이드 | 사이버상담 → 디지털상담 → 가이드북 → 이산중 | 상담 개입 참고(단계·활동) + 절차를 함께 물으면 지금 해야 할 일 |
  | 학생 눈높이 설명 | 사이버상담 → 디지털상담 → 가이드북 → 이산중 | 한 줄 설명·비유·예시·꼭 알려줄 점(학생 말투, 줄마다 근거) |
  | 위기(자해·자살) | 위기대응(PFA-S) → 마음건강 → 정서행동 → 이산중 → 가이드북 | "지금 바로" 5가지, 위기 자료 절차, Wee센터·1388 연계 |

  위기 자료가 여러 개면 이 학교에 그대로 쓸 수 있는 지역(전국·경기·화성·오산·이 학교) 자료 → 정서·위기 주제 자료 → 최근 등록 순으로 앞에 둡니다. 다른 시·도 위기 자료는 뒤로 갑니다.
- 답변은 "## 이산중학교 규정"부터 쓰고, 관련 조항이 없으면 "이산중 규정에는 관련 조항이 없어 가이드북 기준으로 안내합니다"라고 밝힌 뒤 가이드북으로 답합니다.
- 학교폭력 사안은 법정 절차라 가이드북 절차를 함께 안내하고, 학교폭력이 아닌 생활지도 위반은 이산중 학생생활교육규정을 따릅니다. 두 자료가 다르면 법령이 우선임을 밝힙니다.
- 근거 표는 문서 구분 없이 벡터 유사도(코사인) 높은 순으로 보여주고, 자료마다 적용 지역·기준 연도(OCR 자료는 "OCR")를 함께 보여줍니다.
- 다문화·이주배경·북한배경·장애 학생이 질문에 나오면 통역·이주배경 전문가·특수교육 전문가 지원을 절차 안에 넣습니다(규칙 16, 가이드북 필수 항목 검색).
- 다른 시·도 자료를 인용하면 답변 아래 경고, 질문 주제 밖 자료에서 빌린 근거는 따로 표시합니다.
- 자주 묻는 질문 캐시: 대화의 첫 질문이 같고 자료·답변 규칙이 그대로면 저장된 답(`logs/answer_cache.json`)을 바로 보여 주고, "새로 답변 받기"로 다시 만들 수 있습니다.
- 문서와 학교 설정은 `rag.py`의 `DOCS`, `SCHOOL_NAME`에 있습니다. 다른 학교로 바꾸려면 PDF를 `data/`에 넣고 이 두 값을 고친 뒤 `build_index.py`를 다시 실행합니다.

상담 기법·공감·정서 개입은 다루지 않습니다(상담사의 몫).

2. 브라우저에서 http://localhost:8501 이 열림 (안 열리면 주소를 직접 입력)

직접 실행할 때:

```
C:\Users\2003g\anaconda3\envs\DS\python.exe -m streamlit run app.py
```

- 의존성 설치: `pip install -r requirements.txt` (Python 3.10+ 권장)
- 인증: Google Cloud ADC(Application Default Credentials)를 기본으로 사용합니다.
  - 사전 준비: 터미널에서 `gcloud auth login` 및 `gcloud auth application-default login`을 실행합니다.
  - (선택 폴백) 환경변수 `GEMINI_API_KEY` 또는 `.env` 파일의 API Key 인증도 함께 지원합니다.
  - 인증(또는 사용 한도)이 있어야 하는 것: 질문 답변(질문 분석·임베딩·답변 생성), 근거 약함의 뜻 비교·더 맞는 쪽 추천, 자료 추가의 AI 평가와 임베딩, 개정판 교체, 다시 평가·정기 점검, Gemini OCR, `eval/run_eval.py`, `build_index.py`
  - 인증 없이 되는 것: 화면, 이전 대화 다시 보기, 저장된 답변 캐시, 등록 자료 보기·사용 중지·완전 삭제, 적용 지역·연도 고치기, 알림 확인, 중복·판 확인, Windows OCR
  - 사용 한도를 넘으면(429) 화면에 원인과 확인할 곳(Google Cloud 콘솔 / Vertex AI 할당량 및 결제)을 안내합니다.
  - Vertex AI 위치는 `GOOGLE_CLOUD_LOCATION`(기본 `global`). `gemini-3.8-flash`는 `global`에만 있고 `asia-northeast3`에서는 404입니다.
- 모델: `gemini-3.8-flash` (환경변수 또는 `.env`의 `MINDGUIDE_MODEL`로 바꿀 수 있음). 질문 분석은 생각 단계 low로 부릅니다(Gemini 3은 `thinking_level=LOW`, 2.5 계열은 생각 토큰 예산 1024).

## 동작 방식

```
질문 ─▶ ① 질문 정리·검색어 생성(Gemini) ─▶ ② 하이브리드 검색 ─▶ ③ 답변 생성(Gemini) ─▶ 화면
         후속 질문일 때만 이전 질문 반영      벡터(Gemini 임베딩 코사인)      자료 안에서만 답하고
         가이드북 용어 검색어 2~5개           + BM25(형태소) → RRF 합산       [p.쪽] 인용
```

- 인덱스: 10개 자료 → 쪽 단위 청크 1,689개(가이드북 313, 이산중 59, 사이버상담 141, 디지털상담 183, 정서행동 246, 아동학대 231, 성사안안내서 228, 마음건강 134, 학업숙려제 91, 위기대응 63)
  - 저장소 `index/gyeot.db`(SQLite): 문서·층·주제·질문 유형·청크(본문·형태소·`gemini-embedding-001` 3072차원 임베딩)·평가 기록·알림. 자세한 구조는 [docs/DB_설계.md](docs/DB_설계.md)
- 검색(v8): 문서별로 따로 찾아 합칩니다. ① 이산중 규정: 원 질문 6 + 검색어별 3(최대 12청크) ② 가이드북: 원 질문 8 + 검색어별 5(최대 24청크), 검색된 본문이 `<양식2-4>`처럼 부록 양식을 가리키면 그 양식 앞 2쪽을 함께 넣음(최대 3개 양식) ③ 상담 매뉴얼: 문서마다 원 질문 4 + 검색어별 2(최대 7청크). 가이드북 부록3(법령 원문)·매뉴얼 연구방법·참고문헌은 순위를 낮췄습니다. 설정은 `rag.py`의 `RETRIEVAL`. 자료가 늘어도 본 질문 검색은 합계 60청크를 넘지 않게 1·2순위 자료 몫은 그대로 두고 나머지를 줄입니다(`fit_budget`).
- 답변 형식: 정의·요건·기한 같은 사실 질문은 바로 답하고, 상황 질문은 "지금 해야 할 일 / 연계 기관 / 유의사항 / 양식" 구성으로 답합니다.
- 성폭력 관련 단어가 있으면 "수사기관 즉시 신고 의무"를 먼저, 자해·자살 단어가 있으면 위기 유형으로 바꿔 "## 지금 바로" 5가지(혼자 두지 않기, 보호자 알림, 위원회·교육청 보고, 동의 후 연계, 거부 시 대체 지원)를 먼저 안내하고 등록된 위기 자료(PFA-S·마음건강·정서행동)의 절차로 답합니다.

## 자료 관리(추가·사용 중지·완전 삭제·정기 점검)

사이드바에서 **📚 자료 관리**를 고르면 세 메뉴가 있습니다. 자료는 모두 SQLite 저장소 `index/gyeot.db`에 있고, 설계는 [docs/DB_설계.md](docs/DB_설계.md)에 정리했습니다.

**📥 자료 추가**
1. PDF 업로드(같은 PDF가 이미 있으면 파일 해시로 막음) → **AI 평가 실행**
2. `doc_agent/agent.py`가 12개 기준(`doc_agent/criteria.json`)으로 판단: 자동 측정 + Gemini 판단(기준마다 0/1/2점과 근거 쪽) + 코드로 최종 판정(필수 기준 0점 또는 55% 미만 → 비추천, 75% 이상이고 0점 없음 → 추천, 그 사이 → 조건부)
3. 상담사가 인용 이름·정식 이름·층(공통/주제/학교)·주제·질문 유형을 확인하고 승인(조건부는 주의 확인, 비추천은 사유 입력)
4. `doc_agent/ingest.py`가 한 트랜잭션으로 등록하고 그 자료 청크만 임베딩해 저장. 평가의 주의할 점은 '사용 전 알림'으로 남음

**🗂️ 등록 자료**: 자료별 상태·층·주제·청크 수·최근 판정·알림 수·다음 점검일. 자료를 골라
- **사용 중지 / 다시 사용**: 검색에서만 빼기(기본 자료도 가능)
- **지금 다시 평가**
- **완전 삭제**(확인 체크 필요): 저장소의 자료·청크·평가 기록·알림과 `data/`·`doc_agent/inbox/`의 PDF를 지움. 기본 4개 자료는 인용 이름을 입력해 한 번 더 확인해야 지워지고, 지운 자리는 자료 추가에서 다시 채울 수 있음
- **적용 지역·기준 연도 고치기**: 자료마다 전국/경기/화성·오산/학교/다른 시·도와 기준 연도를 지정

등록 대기(2026-10-23, `doc_agent/inbox/`, AI 평가 전): `2025_위(Wee) 클래스 및 센터 운영 가이드.pdf`(wee.go.kr), `2025_제14회 위(Wee) 희망대상 우수사례집.pdf`(wee.go.kr), `2021_단위학교 위기관리 가이드라인(서울특별시교육청).pdf`(학생건강정보센터, 2021년 판).

발행 연도 읽기(`dedupe.year_info`): 표지 → 발행 정보(마지막 3쪽, 부칙 개정 이력처럼 여러 해면 가장 늦은 해) → 본문 → 등록 정보 → 파일 이름 → 제목 순. "2024 TR-34" 같은 보고서 번호는 연도로 보지 않고, 표지에 네 자리 연도가 없으면 "연구보고 25-위센터02"의 두 자리 연도(2025)를 씁니다.

### 학기별 정기 점검과 사용 전 알림

- **앱을 열 때 점검 시기가 지났으면 자동으로 백그라운드 점검**을 시작합니다.
- 앱을 열지 않아도 점검하려면 `run_review.bat`을 Windows 작업 스케줄러에 등록합니다(시기가 아니면 바로 끝남). 예: 매주 월요일 9시에 확인

```
schtasks /Create /TN "곁 정기 점검" /TR "C:\Users\2003g\Documents\Project_sesac\gyeot\run_review.bat" /SC WEEKLY /D MON /ST 09:00
```

- 알림은 챗봇 사이드바("🔔 자료 유의사항 N건")와, 답변이 인용한 자료에 주의·긴급 알림이 있을 때 답변 바로 아래 "사용 전 확인" 상자로 보입니다.
- 명령줄: `python doc_agent\periodic_review.py [--force]`, 평가만: `python doc_agent\agent.py "PDF 경로"`

## 화면에서 확인할 것

- **사용 전 확인**(답변 바로 아래): 인용 자료의 주의·긴급 알림(경고 상자), 참고 알림(접힌 목록), OCR 자료·다른 지역 자료·주제 밖 자료 표시
- **근거 약함**: 인용한 쪽과 단어·뜻이 모두 맞지 않는 줄(단어 < 0.35, 뜻 < 0.70), [일반 원칙]과 쪽을 함께 단 줄(뜻 < 0.75), 단어 겹침이 낮고 다른 검색 쪽이 뜻으로 0.08 이상 더 가까운 줄. 이번에 검색된 쪽 중 더 맞는 쪽을 추천
- **근거 표**(답변 바로 아래): 순위, PDF 쪽, 인용 여부(✅), 벡터 유사도(코사인), BM25 점수, 적용 지역·연도, 장 이름
- **근거 원문 보기**: 검색에 쓴 질문, 생성된 검색어, 청크 원문, 매칭된 검색어, 원본 쪽 이미지
- 검색되지 않은 쪽을 인용하면 노란 경고가 뜹니다.

## 테스트 기록

모든 질문·답변이 `logs/chat_log.jsonl`에 한 줄씩 쌓입니다(질문, 정리된 질문, 검색어, 답변, 인용 쪽, 근거별 쪽·코사인·BM25·인용 여부·매칭 검색어·원문 텍스트).

가이드북을 처음 검토한 요약은 `docs/가이드북_검토_요약.md`에 있습니다.

키 없이 한 점검(2026-10-23): Gemini 응답을 흉내 내는 가짜 클라이언트와 저장소 사본으로 엔진 26·등록 17·화면 29개 항목을 확인해 모두 통과했습니다(답변 품질·속도는 실제 평가로 확인해야 함).
