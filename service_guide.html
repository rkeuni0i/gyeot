1. 한눈에 보는 구조

① 질문상담사가 상황이나 궁금한 점을 입력(예시 질문 버튼도 있음)
→
② 질문 이해Gemini가 질문을 정리하고 검색어·질문 유형·주제·질문 조각을 판단, 위기·성·학생 특성(다문화·장애) 신호 감지
→
③ 자료 검색유형별 순서대로 문서마다 찾음(벡터 + 형태소 하이브리드), 조각별·필수 항목 검색을 동시에, 본 질문은 합계 60청크 안에서
→
④ 답변자료 안에서만 답하고 문장마다 [자료 p.쪽] 근거(스트리밍·정지), 근거 약함 검사·더 맞는 쪽 추천, "사용 전 확인"
🗄️ 자료 저장소 index/gyeot.db(SQLite, 구조 v2): 문서·층(공통/주제/학교)·주제·질문 유형·적용 지역·기준 연도·OCR 여부·청크·임베딩·평가 기록·알림을 한 파일에 보관. 자료 관리 화면에서 추가(AI 평가 → 승인)·사용 중지·완전 삭제, 학기별 정기 점검이 같은 저장소를 씁니다.

2. 화면과 기능

💬 챗봇

  • 질문 입력, 예시 질문, 새 채팅, 이전 대화 다시 열기
  • 답변 위: 🔎 질문 유형·확인 순서, 🧩 질문 분해
  • 답변: 유형별 형식, 문장마다 근거 쪽, 스트리밍·정지 버튼
  • 답변 아래: 사용 전 확인(주의·긴급 경고, 참고 알림 접힌 목록, OCR·다른 지역·주제 밖 자료 표시), 근거 약함(더 맞는 쪽 추천), 근거 표(적용 지역·연도), 근거 원문·원본 쪽 이미지
  • 같은 첫 질문은 저장된 답을 바로 보여 줌(새로 답변 받기)
  • 사이드바: 학교 정보·연계 기관, 새 채팅·자료보관, 근거 자료, 이전 대화, 설정 · 오른쪽 위 🔔 알림 배지
  • 질문·답변·근거가 logs/chat_log.jsonl, 대화가 logs/conversations/에 저장

📚 자료 관리

  • 자료 추가: PDF 올리기 → (글자층 없으면 OCR) → 본문 기반 중복·판 확인 → AI 평가(12개 기준) → 적용 지역 등 확인·승인(개정판이면 교체 동의) → 진행 막대 → 바로 검색
  • 등록 자료: 주제 꼬리표·상태·층·적용 지역·연도·OCR·청크·최근 판정·알림·다음 점검일, 지역·연도 고치기, 사용 중지·다시 평가·완전 삭제
  • 알림·정기 점검(오른쪽 위 🔔): 마지막/다음 점검일, 지금 점검, 알림 "확인함"

⚙️ 자동으로 일어나는 일

  • 앱을 열 때 점검 시기(182일)가 지났으면 백그라운드 정기 점검
  • 자료 추가 때 평가의 주의할 점·OCR 여부 → 참고 알림, 0점 기준 → 주의 알림
  • 답변이 인용한 자료에 주의·긴급 알림이 있으면 답변 아래 경고, 참고 알림은 접힌 목록
  • 다른 시·도 자료를 인용하면 경고
  • (선택) run_review.bat을 작업 스케줄러에 등록하면 앱을 열지 않아도 점검

3. 사용 흐름 시뮬레이션

7. 실행과 파일

실행

run.bat 더블클릭 → http://localhost:8501. 저장소가 없으면 먼저 만듭니다. API 키는 환경변수나 .env의 GEMINI_API_KEY, 모델 gemini-3.8-flash. 키(또는 사용 한도)가 없으면 질문 답변·자료 평가·등록은 할 수 없고, 화면·이전 대화·자료 보기·사용 중지·지역 수정은 됩니다.
