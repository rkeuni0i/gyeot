1. 한눈에 보는 구조

① 질문상담사가 상황이나 궁금한 점을 입력(예시 질문 버튼도 있음)
→
② 질문 이해Gemini가 질문을 정리하고 검색어·질문 유형·주제를 판단
→
③ 자료 검색유형별 순서대로 문서마다 찾음(벡터 + 형태소 하이브리드), 본문이 가리키는 양식 쪽도 함께
→
④ 답변자료 안에서만 답하고 문장마다 [자료 p.쪽] 근거, 알림이 있으면 "사용 전 확인"
🗄️ 자료 저장소 index/mindguide.db(SQLite): 문서·층(공통/주제/학교)·주제·질문 유형·청크·임베딩·평가 기록·알림을 한 파일에 보관. 자료 관리 화면에서 추가(AI 평가 → 승인)·사용 중지·완전 삭제, 학기별 정기 점검이 같은 저장소를 씁니다.

2. 화면과 기능

💬 챗봇

  • 질문 입력, 예시 질문 11개, 대화 초기화
  • 답변 위: 🔎 질문 유형·확인 순서
  • 답변: 유형별 형식, 문장마다 근거 쪽
  • 답변 아래: 사용 전 확인(알림), 근거 표(코사인 순), 인용된 근거 원문·원본 쪽 이미지
  • 사이드바: 근거 자료 목록, 🔔 유의사항 N건, 질문 유형별 확인 순서
  • 모든 질문·답변·근거가 logs/chat_log.jsonl에 저장

📚 자료 관리

  • 자료 추가: PDF 업로드 → 같은 PDF 차단 → AI 평가(12개 기준) → 추천/조건부/비추천 → 상담사 승인 → 바로 검색
  • 등록 자료: 상태·층·주제·청크·최근 판정·알림·다음 점검일, 사용 중지·다시 평가·완전 삭제
  • 알림·정기 점검: 마지막/다음 점검일, 지금 점검, 알림 "확인함"

⚙️ 자동으로 일어나는 일

  • 앱을 열 때 점검 시기(182일)가 지났으면 백그라운드 정기 점검
  • 자료 추가 때 평가의 주의할 점 → 알림
  • 답변이 인용한 자료에 주의·긴급 알림이 있으면 답변 아래 표시
  • (선택) run_review.bat을 작업 스케줄러에 등록하면 앱을 열지 않아도 점검

6 적용 지역전국 공통·경기인지, 다른 시도 고유 규정인지
7 자료 유형실무 매뉴얼 / 연구보고서 / 논문·사례집

9 텍스트 추출 ★스캔본·표 비중(검색되는지)
10 개인정보 ★가려지지 않은 이름·연락처(외부 API 전송)
11 주제 분류학교폭력·가정·학업·정서위기·디지털·상담 기법·학교 운영
12 이용 조건공개 자료인지, 전재·재배포 제한

★ 필수 기준 중 0점 또는 55% 미만 → 비추천 · 75% 이상이고 0점 없음 → 추천 · 그 사이 → 조건부. 비추천도 상담사가 사유를 적으면 추가할 수 있습니다.
