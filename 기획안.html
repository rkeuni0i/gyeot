2문제 정의와 현직 상담교사 인터뷰

문제

  • Wee 클래스 전문상담교사는 대부분 학교에 혼자 있어, 학교폭력 신고·보고 기한, 학업중단 숙려제, 위기 연계처럼 절차가 정해진 일을 바로 물어볼 사람이 없다.
  • 근거가 수백 쪽짜리 가이드북·매뉴얼·학교 규정에 흩어져 있고, 매년 개정된다. 지역(교육청)과 학교마다 세부 기준이 다르다.
  • 일반 AI 답변은 근거가 없거나 다른 지역·이전 연도 기준이 섞여, 상담교사가 그대로 믿고 쓰기 어렵다.

현직 상담교사 인터뷰에서 나온 요구와 반영

81단계 남은 과제 계획

A. 실제 참고 자료 넓히기

  • 현직 상담교사에게 실제로 보는 자료 목록을 받는다(교육청 지침, 위기 대응, 연계 기관, 학교 규정 서식).
  • 자료마다 OCR(필요 시) → 중복·판 확인 → AI 평가 → 승인. 지역이 다른 자료는 경기도교육청 배포본으로 바꿔 찾는다.
  • 비어 있는 주제(가정·아동학대)를 우선 채운다: 교육부 「아동학대 예방 및 대처요령 교육부문 가이드북」(경기도교육청 배포).

완료 기준: 주제 7개 모두 자료 1개 이상, 상담교사 확인

B. 벡터 유사도 임계점 정하기

  • 평가 질문의 정답 쪽·실제 인용 쪽과 검색된 쪽의 코사인 값을 모아, 임계점별 정밀도·재현율을 그린다.
  • 용도별로 나눠 정한다: ① 근거 원문 목록에 보일 기준 ② "근거 부족" 경고 기준 ③ 검색 후보에서 뺄 기준.
  • 지금은 인용된 쪽만 원문에 보여 주고, 초기에는 0.75를 썼다. 자료 수가 늘면 분포가 바뀌므로 자료 20개 이후 다시 잰다.

완료 기준: 임계점과 근거 그래프를 문서화, 화면에 반영

C. 방대한 문서 처리 시간 줄이기

  • 지금: 116쪽 Gemini OCR 약 5분, 질문당 평균 23초(유형 판단 1회 + 답변 1회 + 임베딩).
  • OCR·임베딩: 배치 크기·동시 실행 수 조정, 백그라운드 작업으로 돌리고 진행 막대·완료 알림.
  • 질문: 검색어 임베딩을 한 번에 묶기, 자주 묻는 질문 결과 캐시, 검색 후보 수(budget) 자료 수에 맞춰 조정.
  • 저장소가 커지면 벡터를 미리 메모리에 올리거나 pgvector로 옮긴다.

완료 기준: 질문 평균 15초 이하, 품질 하락 없음(평가 질문 재측정)

D. 지역·기준 연도 구분

  • 자료마다 적용 지역(전국/경기/화성·오산 교육지원청/학교)과 기준 연도를 저장하고, 등록 화면에서 고칠 수 있게 한다.
  • 답변 근거에 "경기도교육청 2026 기준"처럼 표시하고, 학교 지역과 다른 자료를 인용하면 경고한다.
  • 연도 인식 개선: 표지의 보고서 번호("2024 TR-34")를 발행 연도로 읽는 문제(마음건강 가이드북이 2024로 저장됨, 실제 2025.1 발행).

완료 기준: 모든 자료에 지역·연도 표시, 다른 지역 인용 시 경고

묶음만드는 법보는 것
상담 케이스Wee 희망대상 우수사례집 42건을 주제별(학교폭력·가정·학업·정서·디지털)로 2~3건씩 골라 질문으로 바꾸고, 사례의 실제 개입(연계 기관·절차·상담 방식)을 기준 답으로기준 답의 핵심을 담았는지, 맞는 자료부터 찾았는지
근거 일부·추론 필요자료에 직접 문장은 없지만 여러 쪽을 합치면 답할 수 있는 질문(예: 사이버폭력 피해 학생 상담 + 학교 절차)근거 있는 부분과 추론한 부분을 구분해 쓰는지, 지어내지 않는지
근거 없음등록 자료 밖의 실무 질문(예: 특정 학부모 응대 요령)"자료에서 확인되지 않습니다"와 확인할 곳을 안내하는지 → 2단계 커뮤니티로 넘길 질문 후보

발표용 사례 정리

잘 되는 사례(2~3개 후보)

  • 학교폭력 신고 후 교육지원청 보고 기한
  • 학업중단 의사 학생의 숙려제 연계(이산중 제40조 + 경기도교육청 매뉴얼 + 화성시 센터)
  • 사이버 비행을 학생 눈높이로 설명

잘 안 되는 사례(2개 후보)

  • 절차와 상담이 섞인 질문(평가 Q14, 67~83%): 한 유형만 골라 다른 쪽 내용이 빠짐
  • 공식 자료에 없는 실무 노하우 질문: 답할 근거가 없음 → 2단계 필요성

102단계: 상담교사 커뮤니티(지식 공유)

공식 자료만으로 풀기 어려운 실무 질문을 동료 상담교사에게 묻고, 검증된 노하우를 쌓아 AI 답변의 보조 근거로 쓴다.

기능 구상

  • 챗봇에서 이어지기: "자료에서 확인되지 않습니다" 답변에 [동료에게 묻기] 버튼 → 질문을 익명 게시
  • 질문·답변: 지역·학교급·주제 꼬리표, 답변에 근거 자료 연결
  • 검증: 동료 추천 수 + 경력 상담교사·관리자 검증 표시, 공식 지침과 충돌하면 표시
  • 노하우 카드: 검증된 답을 요약 카드로 만들어 'community' 층 자료로 저장 → 챗봇이 [동료 노하우] 근거로 인용(공식 근거와 구분, 공식 지침이 우선)
  • 지역별 모음: 같은 교육청 상담교사끼리 지역 지침·연계 기관 정보 공유

전제 조건

  • 로그인과 상담교사 인증(소속 학교·지역)
  • 여러 사용자가 함께 쓰는 서버와 저장소(PostgreSQL + pgvector)
  • 개인정보 비식별화: 학생 이름·학교·사건 세부를 자동 탐지·가림, 게시 전 확인
  • 운영 정책: 신고·삭제, 공식 지침과 다른 내용 표시, 답변의 책임 범위 안내

1단계에서 이어지는 것

  • 자료 층 구조에 'community' 층 추가(공통/주제/학교와 같은 방식)
  • 근거 표시·사용 전 알림·학기별 점검을 노하우 카드에도 적용
주의 커뮤니티 글은 공식 근거가 아니므로 답변에서 반드시 구분해 보여 주고, 법령·교육청 지침과 다르면 공식 지침을 우선한다.

11위험 요소와 대응

위험대응
학생 개인정보 입력화면 경고, 질문·OCR이 Google Gemini API로 전송됨을 안내. 2단계에서 자동 가림 추가
자해·자살 위기 질문위기 신호 감지 시 학교 위기관리 절차·전문기관 연계를 먼저 안내. 등록된 위기 자료(마음건강 가이드북)만 근거로, 다른 상황의 상담 요령을 옮겨 쓰지 않음
OCR 오탈자OCR 자료 표시와 "숫자·표는 원본 쪽 이미지로 확인" 알림, 답변 근거에 원본 쪽 이미지 제공
낡은 지침학기별 정기 점검, 법령 시행일 비교, 개정판 교체 흐름
다른 지역 지침 혼입AI 평가의 지역 적합성 기준, 8-D의 지역·연도 표시와 경고
외부 API 의존인터넷이 막히면 Windows OCR·맑은 고딕 대체. 모델은 환경변수로 교체 가능
